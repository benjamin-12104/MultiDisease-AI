# MultiDisease AI 
### MultiDisease AI - An AI-Powered Multi-Disease Risk Prediction System


1. A web application that uses Machine Learning to predict the risk of **Diabetes, Heart Disease, and Chronic Kidney Disease** based on health information provided by the user.
2. The project has a **React frontend** and **FastAPI backend**, with SHAP-based explainability to show which factors contributed to the prediction. The results are displayed using interactive charts along with a risk score and risk level.
3. Will be adding **RAG** and **NLP**...

### Tech Stack
- React
- Tailwind CSS
- FastAPI
- Python
- Scikit-learn
- SHAP
- Pandas & NumPy
- Axios

### Features
- Multi-disease risk prediction
- Risk score and risk level
- SHAP-based prediction explanations
- Interactive visualizations
- Input validation
- REST API integration

> **Note:** This project is for educational purposes and should not be used as a substitute for professional medical advice.
